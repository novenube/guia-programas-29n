# Guía de programas · Elecciones generales 29-N 2026

Guía neutral y comprobable de los programas oficiales de los partidos, con un test de afinidad y un comparador de dos partidos.
No recomienda ningún voto. Hecha con inteligencia artificial; puede tener errores y no ha sido revisada por una persona.

- `index.html`: la guía (partidos, mi provincia, España hoy, contraste con datos oficiales, antecedentes, metodología).
- `afinidad.html`: test de afinidad (todo se calcula en el navegador; no se guarda ni se envía nada).
- `comparar.html`: comparador de dos partidos.

**Web:** https://novenube.github.io/guia-programas-29n/

Son tres ficheros HTML sin dependencias externas: funcionan abriéndolos en el navegador o desde cualquier alojamiento estático.
